# Vines Velvet

A starter product website for a multi-device relationship mega hub.

## Features
- Bold product positioning for a couples relationship platform
- Multi-device experience overview (phone, tablet, desktop, watch)
- Core feature pillars and roadmap
- Pricing and plan breakdown
- Privacy and safety messaging
- Modern React + Vite foundation

## Getting started

```bash
npm install
npm run dev
```

Then open the local Vite URL in your browser.
